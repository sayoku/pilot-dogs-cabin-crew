# CONTRIBUTING.md

Rules for every teammate working in this repo, especially when driving an AI coding agent. The agents follow AGENTS.md. These rules are for you.

## Working with your agent

- Give your agent one small task at a time. Do not ask for a whole feature across many files in one prompt. Break it up, then verify and commit after each piece.
- Read and approve the agent's plan before it writes code.
- Never merge code you do not understand line by line. If you cannot explain it, ask the agent to explain it or rewrite it simpler.
- Run the app and the tests yourself before opening a PR.

## Security and privacy

- Never paste Pilot Dogs private information, the real database, API keys, or credentials into any AI tool.
- Watch for code that looks copied from somewhere else. When in doubt, ask where it came from.

## Accountability

- Note the AI tools you used in your PR.
- You own what you push. "The AI wrote it" is not an excuse for a bug.
